# NFL Fix 16 - QB Calibration Eligibility Filter

Purpose:
- Keep QB replacement calibration clean.
- Only grade situations where Macabets knew before kickoff that QB1 was unavailable.

Eligible:
- QB1 ruled unavailable before kickoff
- Replacement QB starts
- Game completed
- Status was known before analysis

Ignored:
- QB1 starts and gets hurt during game
- Backup only appears in garbage time
- QB uncertainty that resolves before kickoff
- Incomplete games

Audit only. Does not change predictions.
